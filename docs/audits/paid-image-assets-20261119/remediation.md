# 썸네일 분리 및 원본 복구 수정

- 유료 장식 108개, 캘린더 팩 표지 8개, 개별 테마 320개, 장면 팩 표지 1개: 총 437개 정적 썸네일을 실제 WebP로 확인했다. 최대 파일 크기는 20630바이트다.
- 캘린더 목록은 `PAID_CALENDAR_THUMBNAILS`를 사용하며 적용 원본 URI와 분리했다. 원본 320개와 포토월·장식 적용 파일을 썸네일로 덮어쓰지 않았다.
- 별도 장면 팩 미리보기는 번들 180px WebP를 사용한다. 적용/다운로드 파일과 분리했다.
- 필름 썸네일은 96px 무손실 중간 PNG를 네이티브 `SaveFormat.WEBP`로 인코딩한 뒤 전달한다. WebView의 WebP 인코딩 지원 여부에 의존하지 않는다. 인코딩 중에는 사용자 원본 JPEG를 썸네일 대신 표시하지 않는다. 생성 파일은 해제 시 정리하고 입력 변경 전의 늦은 결과는 폐기한다. 실제 기기 WebP 인코딩 동작 확인은 아직 하지 않았다.
- 기본형 유료 집게·카메라·휴지통은 `useAppliedDiaryImage`를 통해 설치 파일을 검증/복구한 후 표시한다. 다운로드 실패 시 번들 저해상도 이미지를 대신 표시하지 않는다. 자동 재시도는 최대 60초 간격으로 제한하고 해제 시 취소한다. 버튼의 터치 영역은 유지된다.
- 기존 원본의 실제 디테일과 해상도는 보존했다. 32개 소형 장식과 720×960 장면을 1536px 신규 원본으로 재제작한 것은 아니다. 단순 보간 확대로 디테일이 개선됐다고 보고하지 않는다. 작은 장식과 3배 밀도 프레임 조각은 기존 사용 규격을 유지한다. 모든 원본을 일률적으로 1536px 이상으로 새로 제작하려면 이 부분은 별도 작업이 남는다.

검증: TypeScript 검사 통과. 관련 5개 테스트 스위트 15개 테스트 통과(원본 확인 전 썸네일 미표시, 오프라인 실패, 무료 원본 유지, 다운로드/팩/캘린더/필름 UI). 실제 기기에서 네트워크 중단 및 복구를 포함한 종단 검증은 아직 수행하지 않았다.
