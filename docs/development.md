# 개발 구조와 작업 원칙

갱신일: 2026-10-27

## 시작점

제품의 목적은 [정체성](product/identity.md), 공개 기능은 [현재 기능](product/current-product.md), UI는 [종이와 만년필 디자인](design/paper-and-ink.md)을 확인합니다. 파일이나 토큰에 남은 예전 이름을 제품 방향으로 해석하지 않습니다.

## 구조

레이어는 `src/application → pages → widgets → features → entities → shared` 순서입니다. 루트 `app/`은 Expo Router의 파일 기반 라우트입니다.

| 위치 | 역할 |
|---|---|
| `app/` | 라우트와 앱 레이아웃 |
| `src/application` | 전역 초기화와 프로바이더 |
| `src/pages` | 화면 조립과 탐색 배선 |
| `src/widgets` | 화면 안의 복합 UI |
| `src/features` | 사용자 기능과 유즈케이스 |
| `src/entities` | 도메인 타입·규칙·상태 |
| `src/shared` | 공용 UI·설정·저장 접근·유틸리티 |

상위 레이어에서 하위 레이어로 의존합니다. 새 코드에서 같은 레이어의 다른 슬라이스를 직접 결합하지 않습니다. 공통 기능은 적절한 하위 레이어로 옮기거나 조립 위치에서 연결합니다. 이번 문서 갱신이 기존 의존성 전체의 리팩터링을 뜻하지는 않습니다.

`ui`, `model`, `lib`, `api`, `config`처럼 목적이 드러나는 세그먼트를 사용합니다. `@pages`, `@widgets`, `@features`, `@entities`, `@shared`, `@app` 별칭은 `tsconfig.json`을 기준으로 합니다.

## 상태와 데이터

- 화면 안의 임시 선택·입력·모달 상태는 로컬 상태로 둡니다.
- 여러 화면이 공유하는 도메인 상태는 기존 Zustand 스토어와 저장 헬퍼를 우선 사용합니다.
- 저장은 `localStorageClient`와 도메인 저장 함수를 경유합니다. UI에서 별도의 원시 저장 키를 임의로 만들지 않습니다.
- 기존 ID·저장 키·번역 키를 문구 변경과 함께 일괄 치환하지 않습니다.
- 일기별 이름과 내용은 일기에 속합니다. 새 일기 초안은 기본 이름과 새 상태로 시작합니다.
- 세션·알림 시간은 절대 시각과 도메인 상태를 기준으로 계산합니다. 실행 기능이 존재한다는 이유로 모든 화면을 세션 중심으로 재구성하지 않습니다.
- 저장·삭제·초기화 변경은 기존 기록 보존과 재실행 복구를 확인합니다.

## 화면과 번역

- 라우팅은 `app` 또는 페이지의 조립 지점에서 처리하고 하위 UI에는 콜백을 전달합니다.
- 사용자 문구는 `src/shared/lib/i18n`을 사용합니다. 앱 지원 언어는 `locale.ts`의 현재 목록을 확인합니다.
- 날짜·시간·주인공·메이트·장면 등 용어를 구분하고 긴 문구와 작은 화면을 확인합니다.
- 플래그가 꺼진 기능을 안내 문구나 튜토리얼에서 임의로 노출하지 않습니다.
- 카드 전환, 이름 입력, 튜토리얼과 키보드 경로를 스타일 변경 중에도 보존합니다.

## 검증

작업에 맞는 테스트와 타입·코드 검사를 실행합니다. 저장 구조·튜토리얼 분기처럼 실패 영향이 있는 동작은 관련 회귀 테스트를 유지합니다. 단순한 문서 갱신에 앱 전체 테스트를 반복 실행하지 않습니다.

```sh
npm run typecheck
npm run lint
npm test -- --runInBand
```

기존 실패와 이번 변경에서 생긴 실패를 구분해 보고합니다. 수동 확인은 [회귀 확인 목록](regression-checklist.md)의 영향받는 항목을 사용합니다.

## 설정과 실행

서비스 설정은 [데이터와 외부 서비스](product/data-and-services.md)를 확인합니다. 에이전트는 사용자가 허용한 범위 안에서 작업하며 Expo CLI 실행은 [프로젝트 규칙](../.cursor/rules/pokit-Expo.mdc)을 따릅니다. 네이티브 프로젝트 재생성·배포는 문서 갱신 작업에 포함되지 않습니다.
