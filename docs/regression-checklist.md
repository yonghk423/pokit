# 오늘의 주인공 회귀 확인 목록

갱신일: 2026-10-27

변경에 영향받는 항목만 확인합니다. 공개되지 않은 기능을 검증하려고 플래그를 임의로 켜지 않습니다.

## 일기와 주인공

- [ ] 새 일기 추가 시 기본 주인공 이름으로 시작하고 기존 일기의 이름은 유지된다.
- [ ] 주인공 썸네일을 누르면 대표 이미지와 선택한 주인공이 함께 바뀐다.
- [ ] 오른쪽 썸네일은 막대가 보이지 않아도 위아래로 스크롤된다.
- [ ] 작은 주인공 미리보기와 iPad의 큰 메인 장면 카드가 각각의 공간에 맞게 표시된다.
- [ ] 장면 추가·순서·변경·메모·할 일·완료 상태가 저장되고 앱 재실행 후 복원된다.
- [ ] 카드 회전으로 상세에 들어가고 닫을 때 이미지가 겹치거나 흐려지지 않는다.
- [ ] 보관함 검색·열기·이름 변경·삭제가 올바른 일기에 적용된다.
- [ ] 빈 노트 + 아이콘은 새 일기를 만든다. 검색 결과 없음과 빈 보관함의 안내는 구분된다.

## 튜토리얼

- [ ] 직접 이름을 입력하고 시작하기를 눌러도 튜토리얼이 이어진다.
- [ ] 직접 버튼을 누르는 경로와 ‘나중에’ 경로가 같은 다음 상태로 이어진다.
- [ ] 장면 상세를 닫고 다음 단계로 넘어갈 때 이미지가 중복되지 않는다.
- [ ] 현재 안내 캐릭터가 유지되고 대상 버튼에 만년필 표시가 정확히 놓인다.
- [ ] 메이트·도구 등 안내된 UI가 실제로 열리고 닫힌다.
- [ ] 날씨를 볼 수 있는 상태에서 날씨 대상 표시와 상세 열기·닫기가 작동한다.
- [ ] 종료 후 복귀 화면과 리뷰 요청 호출이 올바르다. 실제 리뷰 모달 표시 여부는 OS가 결정한다.

## 메이트·입력·날씨

- [ ] 메이트 추가·순서 변경·완료와 해당 작업의 저장 경로가 유지된다.
- [ ] 메모 다섯 줄 초과·스크롤·긴 문장에서도 밑줄과 입력 내용이 일치한다.
- [ ] 이름·메모·할 일을 키보드가 가리지 않고 저장·닫기 동작이 가능하다.
- [ ] 날씨 요약과 상세 값이 일치하고 캐릭터는 모달 안에만 표시된다.
- [ ] 날씨 로딩 실패·권한 미허용 시 요약 영역이 숨겨지고 나머지 기능은 계속 작동한다.
- [ ] 새로고침 아이콘의 화살촉과 닫기 X가 알아보기 쉽고 누를 영역이 충분하다.

## 해당 기능을 변경했을 때

- [ ] 세션: 시작·일시정지·재개·완료와 앱 재진입 복구.
- [ ] 알림: 권한, 예약 변경·취소와 기기 시간대.
- [ ] 위젯: 일기·메이트·날씨의 변경 반영과 앱 진입.
- [ ] 다국어: 지원 언어의 누락, 폴백, 긴 문구와 시간 형식.
- [ ] 표시: iPhone·iPad·좁은 창, 다크 모드, 선택 글꼴과 크기.
- [ ] 숨김 기능: 저장 기록이 유지되고 진입점이 갑자기 노출되지 않는다.

## 자동 검사

관련 테스트, `npm run typecheck`, `npm run lint`를 변경에 맞게 실행합니다. 전체 CI가 필요하면 `npm run ci`를 사용합니다. 문서만 바뀐 작업은 링크·경로·폐기된 지침 참조를 확인합니다.
