# Daylight 회귀 확인 목록

갱신일: 2026-11-17

변경에 영향받는 항목만 확인합니다. 공개되지 않은 기능을 검증하려고 플래그를 임의로 켜지 않습니다.

## Diary·Photo·캘린더

- [ ] 날짜 선택 → 사진 선택 → 편집 → 현재 사진에 적용이 해당 날짜 기록에 반영된다.
- [ ] 긴 글과 많은 이벤트가 잘리지 않고, 로딩 중 스켈레톤에서 실제 내용으로 전환된다.
- [ ] Photo의 월별 묶음과 연도 이동, 다이어리의 날짜별 기록이 올바르게 유지된다.
- [ ] 폴라로이드 비율·회전·편집·사진 교체와 앱 재실행 후 복원이 정상이다.
- [ ] 달력 연월·요일·날짜와 터치 영역이 같은 좌표를 사용하며 인물과 하단 탭을 가리지 않는다.
- [ ] 위젯은 달력 날짜별 사진을 렌더링하지 않는다.

## Store·다운로드·Pro

- [ ] 미다운로드 팩은 대표 표지만 보이고 개별 목록을 열 수 없다.
- [ ] 다운로드 n/n이 실제 설치 개수에 따라 증가하며, 전부 완료된 뒤 목록을 열 수 있다.
- [ ] 적용 후 Diary에서 선택한 달력이 표시되고 월 이동과 날짜 선택이 동작한다.
- [ ] 삭제 확인창에서 취소하면 유지되며, 삭제하면 다운로드 파일·적용 상태를 정리한다.
- [ ] 팩 삭제 후 내장 표지·개인 사진·기록은 유지되고 다운로드 버튼으로 돌아온다.
- [ ] 스토어 복합 이미지는 준비 후 함께 표시되며 이미지 캐시 용량 제한과 정리가 유지된다.
- [ ] 일반 캘린더는 무료이며 Pro 팩과 유료 필름은 현재 구독·프로모션 정책을 따른다.
- [ ] 원본·따뜻한 필름·흑백 감성·크림톤과 수동 보정은 무료로 적용·저장·공유된다.
- [ ] Pro 자동 소개는 앱 전체에서 한 번 표시되며 열람 기록과 구독 권한 검사는 구분된다.

## 입력·날씨·일정·안내

- [ ] 긴 문장·스크롤·키보드에서도 입력·저장·닫기 버튼과 내용이 가려지지 않는다.
- [ ] 날씨 로딩·권한 거부·실패 시 실제 구현에 맞는 상태가 표시되고 나머지 기능을 막지 않는다.
- [ ] Google·Apple 일정의 연결·접기·펼치기와 이벤트가 선택한 날짜에 맞게 표시된다.
- [ ] 앱의 안내와 실제 버튼 동작이 일치하고 모달 복귀 시 이미지가 중복되지 않는다.
- [ ] Google Drive 백업·복구를 변경하면 원본·매니페스트·실패 복원과 기존 기록 보존을 확인한다.

## 해당 기능을 변경했을 때

- [ ] 세션: 시작·일시정지·재개·완료와 앱 재진입 복구.
- [ ] 알림: 권한, 예약 변경·취소와 기기 시간대.
- [ ] 위젯: 일기·메이트·날씨의 변경 반영과 앱 진입.
- [ ] 다국어: 지원 언어의 누락, 폴백, 긴 문구와 시간 형식.
- [ ] 표시: iPhone·iPad·좁은 창, 다크 모드, 선택 글꼴과 크기.
- [ ] 숨김 기능: 저장 기록이 유지되고 진입점이 갑자기 노출되지 않는다.

## 자동 검사

관련 테스트, `npm run typecheck`, `npm run lint`를 변경에 맞게 실행합니다. 전체 CI가 필요하면 `npm run ci`를 사용합니다. 문서만 바뀐 작업은 링크·경로·폐기된 지침 참조를 확인합니다.
