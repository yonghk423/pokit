# pokit 회귀 스모크 체크리스트

PR에서 **자동 테스트가 덮지 못하는 화면·OS 연동**은 아래 중 영향 받는 항목만 수동으로 확인합니다.

## 핵심 플로우 (5분)

- [ ] **데이플랜**: 블록 추가·순서 변경·완료 표시
- [ ] **세션** (`activity-session`): 시작 → 일시정지 → 재개 → 완료
- [ ] **앱 재실행**: 일정·세션 진행 상태가 유지되는지
- [ ] **하루 주기**: 시작/마무리 시각 변경이 데이플랜에 반영되는지

## 기능별 (해당 PR일 때만)

- [ ] **목표 상세** → flow-review → 세션 시작
- [ ] **알림**: 일정 변경 후 알림 동기화(권한 허용 환경)
- [ ] **온보딩**: 최초 진입·`DailyRhythmOnboardingGate` 완료 후 본문 진입

## CI (PR마다 자동)

- `npm run lint`
- `npm run typecheck`
- `npm run test` — `entities/day-plan` 등 순수 도메인 로직

로컬에서 CI와 동일하게 돌리려면: `npm run ci`
