# 제품 정체성과 용어

갱신일: 2026-11-17

## 한 문장

**Daylight는 사진과 글로 꾸미는 나만의 다이어리입니다.**

> 사진으로 하루를 남기고, 짧은 글로 기억을 더하세요.

기억하고 싶은 일상을 사진과 글로 기록하고, 폴라로이드와 취향에 맞는 달력으로 다시 돌아보는 경험을 중심으로 설계합니다.

## 기능의 역할

| 기능 | 역할 |
|---|---|
| Diary | 날짜별 글·사진과 계획·메모·이벤트를 기록하는 곳 |
| Photo | 폴라로이드로 꾸민 사진을 월별로 모아 보는 곳 |
| 캘린더 | 날짜와 기록을 연결하고 한 달을 돌아보는 화면 |
| 일러스트 캘린더 | 장면과 달력이 어우러진 디자인으로 기록을 보는 경험 |
| Store | 달력·일러스트 팩·다이어리 장식을 고르고 다운로드·적용하는 곳 |
| 사진 편집 | 수동 보정과 필름 필터로 사진의 분위기를 꾸미는 도구 |
| 날씨·일정 연동 | 일상의 맥락과 계획을 돕는 보조 기능 |

제품 카테고리의 중심은 **포토 다이어리**입니다. 과거의 주인공 선택·장면 구성·메이트를 현재 앱 전체의 대표 경험으로 소개하지 않습니다. 실제 제공 범위와 가격 정책은 [현재 기능](current-product.md)을 확인합니다.

## 지향하는 흐름

1. 기록할 날짜를 고르고 사진을 추가합니다.
2. 사진을 꾸미고 그날의 이야기나 짧은 메모를 남깁니다.
3. 다이어리, 월별 사진 모음, 달력에서 기록을 다시 봅니다.
4. Store에서 취향에 맞는 달력이나 장식을 골라 적용합니다.

## 문구 원칙

- 현재 제품명은 **Daylight**입니다. ‘오늘의 주인공’과 ‘yourday’는 이전 이름입니다.
- 내부의 `pokit`, `comic`, `flow` 같은 식별자는 호환성을 위해 유지하며 사용자용 제품명과 구분합니다.
- 주인공·장면·메이트 등 과거 기능 용어는 해당 기능에만 사용합니다.
- 다음 행동이 명확한 짧은 문구를 쓰고, 기록량이나 성취에 부담을 주지 않습니다.
- 무료 기능과 Pro 기능을 구분하고, 운영 중인 프로모션을 영구적인 무료 제공으로 표현하지 않습니다.
- 원격 테마 다운로드를 사용자 사진·다이어리의 클라우드 백업이나 동기화로 설명하지 않습니다.

이 문서는 현재 제품 소개 기준입니다. 과거 설계 기록이나 화면의 모든 기존 문구가 일괄 변경되었다는 의미는 아닙니다.
