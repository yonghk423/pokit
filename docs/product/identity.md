# 제품 정체성과 용어

갱신일: 2026-10-27

## 한 문장

**오늘의 주인공은 장면을 골라 내 하루를 만드는 다이어리입니다.**

사용자에게 설명할 때는 다음 문장을 사용합니다.

> 장면을 고르고, 할 일을 챙기고, 나의 하루를 남기세요.

긴 글을 쓰기 전에 주인공과 그림 장면으로 시작할 수 있습니다. 하고 싶은 일을 준비하고, 실제로 있었던 일과 생각을 같은 장면에 남기는 경험을 중심으로 설계합니다.

## 기능의 역할

| 기능 | 역할 |
|---|---|
| 주인공과 장면 | 사용자의 하루를 그림으로 표현하는 중심 경험 |
| 장면의 할 일 | 그 장면에서 하고 싶은 행동 |
| 장면의 메모 | 있었던 일과 남기고 싶은 생각 |
| 오늘의 메이트 | 하루를 준비하고 실행하도록 돕는 항목과 도구 |
| 반복 설정·루틴 | 자주 하는 일을 다시 입력하는 부담을 줄이는 방법 |
| 일기 보관함 | 만들어 둔 하루와 이야기를 다시 보는 곳 |
| 날씨 | 오늘의 상황과 분위기를 더하는 보조 정보 |

제품 카테고리의 중심은 **다이어리**입니다. 투두와 루틴을 동등한 별도 제품처럼 소개하지 않습니다. 새로운 기능은 “사용자가 하루를 만들거나 남기는 데 도움이 되는가?”를 기준으로 검토합니다.

## 지향하는 흐름

1. 오늘에 담고 싶은 장면을 고릅니다.
2. 그 장면에서 하고 싶은 일을 적습니다.
3. 일을 마치거나 계획이 바뀌면 상태를 바꿉니다.
4. 메모를 남기고 하루를 다시 봅니다.

예를 들어 ‘서점에서 책 고르기’ 장면에 ‘에세이 한 권 골라 보기’를 적고, 다녀온 뒤 고른 책과 감상을 기록합니다. 해야 할 일과 하루의 기억이 하나의 장면을 중심으로 이어지는 방향입니다.

메이트와 장면의 데이터가 모두 자동 통합되어 있다는 뜻은 아닙니다. 현재 제공 범위는 [현재 기능](current-product.md)을 확인합니다. 데이터 통합이나 새로운 진입 흐름은 별도 구현과 검증이 필요합니다.

## 문구 원칙

- 제품명은 ‘오늘의 주인공’을 사용합니다. 내부의 `pokit`, `comic`, `flow` 같은 식별자를 화면 용어로 그대로 옮기지 않습니다.
- 앱 전체를 가리키는 이름, 주인공 캐릭터, 메이트, 장면을 구분합니다. 모든 기능을 ‘오늘의 주인공’으로 일괄 치환하지 않습니다.
- ‘오늘의 메이트’는 하루를 돕는 항목을 뜻합니다. 반복 동작을 설명할 때는 ‘반복 설정’ 또는 문맥에 맞는 ‘루틴’을 사용합니다.
- 다음 행동이 명확한 짧은 문구를 씁니다. 완료하지 못한 일에 죄책감이나 과도한 성취 압박을 주지 않습니다.
- 빈 상태는 맥락이 명확하면 작은 그림과 추가 동작으로 안내합니다. 접근성 이름은 텍스트로 제공합니다.
- 이름 변경은 해당 일기에 속합니다. 새 일기를 만들 때는 기본 주인공 이름으로 시작합니다.

문구 예시는 설계 기준이며, 번역 사전과 화면의 모든 기존 문구가 이미 갱신되었다는 의미는 아닙니다.
