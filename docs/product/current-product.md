# 현재 기능과 공개 상태

확인일: 2026-10-27. 아래 경로는 확인을 위한 시작점이며 기능의 공개 여부는 실행 중인 설정과 코드를 함께 확인합니다.

| 영역 | 현재 구현 | 확인 위치 |

메이트와 주인공 일기는 관련된 경험이지만 서로 다른 저장 구조와 화면 경로를 갖습니다. 기능을 소개할 때 전체 데이터가 자동으로 서로 연결된다고 표현하지 않습니다.

## 숨김·보류 기능

[src/shared/config/featureFlags.ts](../../src/shared/config/featureFlags.ts)의 값이 실제 기준입니다. 확인 시점에는 퍼즐, 루틴 관리 탭, 루틴 템플릿, 오늘의 한 줄, 일부 화면 진입점과 시간 제한 기능이 꺼져 있습니다.

- 코드나 저장 데이터가 존재하는 것과 사용자에게 공개되어 있는 것은 다릅니다.
- 숨겨진 기능을 설명서·튜토리얼·스토어의 대표 기능으로 소개하지 않습니다.
- 기존 기능의 작업 요청만으로 플래그를 켜거나 데이터를 지우지 않습니다.
- 홈 화면 위젯 구현과 위젯 설치 설명서는 별개입니다. 제거된 위젯 설명서 화면을 자동으로 복원하지 않습니다.

## 유지할 동작

- 카드의 회전·상세 전환 모션은 제품 경험의 일부입니다.
- 튜토리얼에서도 사용자가 직접 누르는 버튼과 안내의 다음 단계가 같은 경로를 따릅니다.
- 입력, 모달 닫기, 화면 복귀 때 장면 이미지가 중복되거나 작은 해상도로 고정되지 않아야 합니다.
- 날씨를 불러올 수 없으면 요약 영역은 숨깁니다.
- 새 일기의 기본 이름과 기존 일기의 사용자 지정 이름을 분리합니다.

검증 항목은 [회귀 확인 목록](../regression-checklist.md)을 사용합니다.


## 일반 캘린더 무료 정책

2026-11-14: 스토어의 **캘린더** 탭에 등록된 일반 달력은 모두 무료입니다. Weather Calendar와 기존 프리미엄 종이 디자인도 포함합니다. Pro 표시와 구독 결제창을 제거했으며, 필요한 에셋은 무료로 다운로드한 뒤 적용합니다. `calendar-store` 서버도 일반 캘린더 ID를 구독 검사에서 제외합니다. 다이어리 장식 아이템의 가격 정책은 별도로 유지합니다.


## 필름 필터 Pro 정책

2026-11-15: 카메라 편집기의 원본 외 필름 프리셋 15종은 Pro 혜택입니다. 모든 필터 미리보기는 가능하며, 사진 적용·앨범 저장·공유 시 Pro 권한을 확인합니다. 취소하면 편집 상태를 유지하고 내보내기를 중단합니다. 원본 및 밝기·대비 등 수동 보정은 무료입니다. `proPolaroidExport` 플래그를 활성화했으며 구독 확인 조건은 필름 프리셋에만 적용합니다. 기존 11월 무료 체험 정책(`proPromotion.ts`, 한국 시간 2026-12-01 00:00 종료)은 그대로 적용됩니다. 저장된 사진은 이 변경으로 삭제되거나 되돌려지지 않습니다.

필름 필터를 처음 선택하면 편집 세션당 한 번 Pro 기능 안내를 표시합니다. 11월 행사 기간에는 무료 체험 및 12월 1일 구독 필요 안내를 함께 보여줍니다. Film 도구와 각 유료 프리셋에 Pro 표시가 있으며, 미리보기 변경을 반복할 때 안내를 계속 띄우지 않습니다.

Pro 소개 화면은 기간·기능 종류와 관계없이 앱 전체에서 한 번만 자동으로 표시합니다. 어떤 유료 기능에서든 소개 화면을 열면 `pokit:pro-introduction-seen`에 열람 여부를 저장합니다. 이후 다른 유료 기능을 사용하거나 앱을 다시 실행해도 소개 화면으로 자동 이동하지 않습니다. 이전 행사 안내 열람 기록도 이어받습니다. 설정에서 직접 Pro 소개를 여는 동작은 유지합니다. 안내 열람 여부와 실제 구독 권한 검사는 별개입니다.
