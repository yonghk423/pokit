# 현재 기능과 공개 상태

확인일: 2026-10-27. 아래 경로는 확인을 위한 시작점이며 기능의 공개 여부는 실행 중인 설정과 코드를 함께 확인합니다.

## 중심 화면

| 영역 | 현재 구현 | 확인 위치 |
|---|---|---|
| 첫 탭 | 주인공과 장면으로 일기를 구성 | `app/(tabs)/_layout.tsx`, `src/pages/day-plan/ui/ComicDayPage.tsx` |
| 주인공 선택 | 그림 미리보기, 오른쪽 세로 썸네일, 이름 입력·수정 | `src/pages/day-plan/ui/HeroCharacterChooser.tsx` |
| 일기와 장면 | 일기 생성·선택, 장면 추가·상세·메모·할 일 | `src/pages/day-plan/ui/IndependentHeroPlanner.tsx` |
| 보관함 | 검색·열기·이름 변경·삭제, 빈 노트 추가 아이콘 | `src/pages/day-plan/ui/HeroDiaryLibrary.tsx` |
| 오늘의 메이트 | 하루를 준비하고 관리하는 항목·도구 | `src/pages/day-plan/ui/DayPlanPage.tsx`, `app/day-plan.tsx` |
| 날씨 | 현재 날씨 요약과 상세 모달, 날씨에 맞는 캐릭터 | `src/pages/day-plan/ui/WeatherSummary.tsx` |
| 튜토리얼 | 주인공·장면·메이트·날씨를 실제 조작하며 안내 | `src/pages/welcome-intro` |
| 설정과 설명서 | 표시·알림 등 설정과 앱 내 사용 가이드 | `src/pages/settings`, `src/pages/guide-book` |

메이트와 주인공 일기는 관련된 경험이지만 서로 다른 저장 구조와 화면 경로를 갖습니다. 기능을 소개할 때 전체 데이터가 자동으로 서로 연결된다고 표현하지 않습니다.

## 숨김·보류 기능

[src/shared/config/featureFlags.ts](../../src/shared/config/featureFlags.ts)의 값이 실제 기준입니다. 확인 시점에는 퍼즐, 루틴 관리 탭, 루틴 템플릿, 오늘의 한 줄, 일부 화면 진입점과 시간 제한 기능이 꺼져 있습니다.

- 코드나 저장 데이터가 존재하는 것과 사용자에게 공개되어 있는 것은 다릅니다.
- 숨겨진 기능을 설명서·튜토리얼·스토어의 대표 기능으로 소개하지 않습니다.
- 기존 기능의 작업 요청만으로 플래그를 켜거나 데이터를 지우지 않습니다.
- 홈 화면 위젯 구현과 위젯 설치 설명서는 별개입니다. 제거된 위젯 설명서 화면을 자동으로 복원하지 않습니다.

## 유지할 동작

- 카드의 회전·상세 전환 모션은 제품 경험의 일부입니다.
- 튜토리얼에서도 사용자가 직접 누르는 버튼과 안내의 다음 단계가 같은 경로를 따릅니다.
- 입력, 모달 닫기, 화면 복귀 때 장면 이미지가 중복되거나 작은 해상도로 고정되지 않아야 합니다.
- 날씨를 불러올 수 없으면 요약 영역은 숨깁니다.
- 새 일기의 기본 이름과 기존 일기의 사용자 지정 이름을 분리합니다.

검증 항목은 [회귀 확인 목록](../regression-checklist.md)을 사용합니다.
