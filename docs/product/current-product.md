# 현재 기능과 공개 상태

소개 갱신일: 2026-11-17. 현재 제품명은 **Daylight**이며 사진·글·폴라로이드·캘린더를 중심으로 한 포토 다이어리입니다. 기능의 공개 여부는 실행 중인 설정과 코드를 함께 확인합니다.

## 중심 화면

| 영역 | 현재 경험 | 확인 위치 |
|---|---|---|
| Diary | 날짜별 글·사진, 계획·메모·이벤트 기록 | `src/pages/day-plan/ui/ComicDayPage.tsx` |
| Photo | 사진 편집과 폴라로이드, 월별 사진 모음 | `app/(tabs)/history.tsx`, `src/pages/day-plan/ui/HeroPolaroidEditor.tsx` |
| Store | 일반 캘린더, 일러스트 캘린더, 다이어리 장식 선택 | `app/(tabs)/calendar.tsx` |
| 캘린더 | 선택한 달력 디자인에 날짜별 기록 표시 | `src/pages/day-plan/ui/HeroIllustrationCalendar.tsx` |
| 일러스트 팩 | 대표 표지 → 다운로드 진행률 → 완료 후 목록 → 디자인 적용·팩 삭제 | `app/calendar-pack.tsx`, `src/pages/day-plan/lib/cityCalendarPack.ts` |
| 날씨·일정 | 날씨 정보와 Google·Apple 일정 연동 | `src/pages/day-plan`, `src/pages/settings` |

일러스트 팩은 Supabase에서 내려받으며 대표 표지는 앱에 내장합니다. 팩 삭제와 개인 사진·기록 삭제는 별개입니다. 원격 에셋 제공을 개인 기록의 클라우드 동기화로 표현하지 않습니다.

과거 주인공·장면·메이트 관련 코드와 문서는 유지될 수 있지만 현재 대표 소개는 위 흐름을 기준으로 합니다.

## 숨김·보류 기능

[src/shared/config/featureFlags.ts](../../src/shared/config/featureFlags.ts)의 값이 실제 기준입니다. 확인 시점에는 퍼즐, 루틴 관리 탭, 루틴 템플릿, 오늘의 한 줄, 일부 화면 진입점과 시간 제한 기능이 꺼져 있습니다.

- 코드나 저장 데이터가 존재하는 것과 사용자에게 공개되어 있는 것은 다릅니다.
- 숨겨진 기능을 설명서·튜토리얼·스토어의 대표 기능으로 소개하지 않습니다.
- 기존 기능의 작업 요청만으로 플래그를 켜거나 데이터를 지우지 않습니다.
- 홈 화면 위젯 구현과 위젯 설치 설명서는 별개입니다. 제거된 위젯 설명서 화면을 자동으로 복원하지 않습니다.

## 유지할 동작

- 카드의 회전·상세 전환 모션은 제품 경험의 일부입니다.
- 튜토리얼에서도 사용자가 직접 누르는 버튼과 안내의 다음 단계가 같은 경로를 따릅니다.
- 입력, 모달 닫기, 화면 복귀 때 장면 이미지가 중복되거나 작은 해상도로 고정되지 않아야 합니다.
- 날씨 로딩·실패·권한 거부 표시는 현재 날씨 UI의 상태 처리와 함께 확인합니다.
- 날짜별 기록과 기존 일기·초안의 상태를 섞지 않습니다. 레거시 일기 이름을 수정하면 해당 기록만 변경합니다.

검증 항목은 [회귀 확인 목록](../regression-checklist.md)을 사용합니다.


## 일반 캘린더 무료 정책

2026-11-14: 스토어의 **캘린더** 탭에 등록된 일반 달력은 모두 무료입니다. Weather Calendar와 기존 프리미엄 종이 디자인도 포함합니다. Pro 표시와 구독 결제창을 제거했으며, 필요한 에셋은 무료로 다운로드한 뒤 적용합니다. `calendar-store` 서버도 일반 캘린더 ID를 구독 검사에서 제외합니다. 다이어리 장식 아이템의 가격 정책은 별도로 유지합니다.


## 필름 필터 Pro 정책

2026-11-17 기준 `HeroPolaroidEffects.tsx`의 `isProPolaroidFilm`을 따릅니다. 원본·따뜻한 필름(`warm`)·흑백 감성(`monochrome`)·크림톤(`cream`)과 밝기·대비 등 수동 보정은 무료이며 나머지 필름 프리셋은 Pro 적용 대상입니다. 필터 미리보기는 가능하고 사진 적용·앨범 저장·공유 시 해당 필름의 권한을 확인합니다. 취소하면 편집 상태를 유지하고 내보내기를 중단합니다. `proPolaroidExport`는 활성화되어 있습니다. 저장된 사진을 가격 정책 변경만으로 삭제하거나 되돌리지 않습니다.

Pro 소개 화면은 기간·기능 종류와 관계없이 앱 전체에서 한 번만 자동으로 표시합니다. 어떤 유료 기능에서든 소개 화면을 열면 `pokit:pro-introduction-seen`에 열람 여부를 저장합니다. 이후 다른 유료 기능을 사용하거나 앱을 다시 실행해도 소개 화면으로 자동 이동하지 않습니다. 이전 행사 안내 열람 기록도 이어받습니다. 설정에서 직접 Pro 소개를 여는 동작은 유지합니다. 안내 열람 여부와 실제 구독 권한 검사는 별개입니다.
