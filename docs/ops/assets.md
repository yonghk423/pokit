# 에셋 관리

갱신일: 2026-10-27

## 기준

- 앱에서 사용하는 최종 에셋은 저장소 안에 둡니다. 개인 생성 폴더나 임시 파일만 참조하지 않습니다.
- 그림체·캐릭터·이미지 비율은 [일러스트와 아이콘](../design/illustrations-and-icons.md)을 따릅니다.
- 장면 이미지는 960px 계열로 통일하고 작은 카드·썸네일·상세의 렌더링을 함께 확인합니다.
- 작은 아이콘의 투명 배경과 필요한 배율을 보존합니다. 코드 기반 아이콘은 크기별 래스터 복제를 만들 필요가 없습니다.
- 썸네일 크기를 줄였다는 이유로 원본 장면 해상도까지 낮추지 않습니다.

## 추가·교체

1. 승인된 그림과 사용 위치를 확인합니다.
2. 기존 파일을 교체하는지 새 파일을 추가하는지 구분합니다.
3. 정적 import/require 등록, 타입·카탈로그·번역·위젯 매핑을 함께 확인합니다.
4. 실제 표시 크기·크롭·모서리·투명도와 고해상도 화면을 확인합니다.
5. 이전 파일의 참조가 남지 않았는지 확인합니다.

메이트 일러스트 검증은 `scripts/verify-routine-illustrations.py`, 장면 생성 경로는 `scripts/generate-comic-thumbnails.py`를 참고합니다.

## 삭제

파일명 검색만으로 미사용을 단정하지 않습니다. 소스 코드, 생성 스크립트, 앱 설정, 정적 에셋 등록, 위젯·네이티브 리소스 참조를 함께 확인합니다. 폴더 이름이나 과거 용량 표를 근거로 일괄 삭제하지 않습니다.

## 용량 측정

과거의 에셋 개수·절감률을 현재 앱 크기로 사용하지 않습니다. 용량을 보고할 때는 측정 날짜, 대상 커밋, 소스 에셋·내보낸 번들·설치 패키지 중 무엇을 잰 것인지 기록합니다. 현재 배포 패키지 크기는 실제 산출물을 측정해야 알 수 있습니다.
