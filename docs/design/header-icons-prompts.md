# Header icon prompt set

Generated using the built-in image generation tool. Drawing style reference: the existing hand-ink calendar illustration for the Today bottom tab.

## Shared prompt

Use case: illustration-story.
Asset type: one custom mobile app header toolbar icon, displayed at only 12–22 points.
Input image is a DRAWING STYLE reference only; create the requested new subject.
Style: the same black ink pen illustration family as the reference: crisp confident subtly organic contours, black-and-white editorial manga stationery drawing, extremely restrained edge hatching, small black masses and generous white space. Simplify far more than the reference for tiny-size clarity: only essential outlines and a handful of interior marks. Stroke weight consistent across the set, roughly 3–4% of the object width. Pure black ink, white object surfaces, actual transparent background outside the object.
Composition: exactly ONE centered compact object icon in a square image, silhouette occupies about 85% of the frame, all details fully in frame with safe padding, no surrounding scene.
Avoid: people, hands, text, letters, numbers, labels, colored accents, large shadows, decorative sparkles, dense crosshatching, tiny fine details, gradients, photorealism, flat generic UI glyphs, app tile backgrounds, outer button boxes, watermarks, multi-icon sheets.

## Subjects

### daily

A small top-bound daily planner pad, one prominent hand-drawn check mark and two simple task lines. A single compact page with a slightly lifted lower corner. No clock or calendar grid.

### lock-memo

A simple upright smartphone with a small square handwritten memo slip resting over the lower part of its screen. One short note line and a tiny pin at the note's top. Recognizable PHONE plus NOTE, not a generic writing app glyph. No keypad or screen UI details.

### note

A small open notebook seen at a slight three-quarter angle, a short pencil resting against its lower right edge, only two faint short writing strokes. Compact balanced silhouette, do not make the pen dominate.

### reading

A single closed hardback book seen at a modest three-quarter angle, a plain black cover panel and a slim bookmark ribbon peeking from the bottom. Keep the page block and spine recognizable, no lettering.

### settings

A single small mechanical cogwheel with six broad teeth and one clear round central hole, modest three-quarter depth. Elegant hand-ink pen outline with one lightly hatched side edge; avoid an industrial machine scene.

### calendar

A small upright desk calendar with two binding loops, a simple three-by-three date grid and one bold circular marked date cell. No numerals, no letters. A clear distinct silhouette from a checklist planner.

### clock

A single round analog clock face shown straight on, two bold hands pointing to approximately 9:00, four small tick marks only, one very subtle lightly hatched rim. No numerals, no feet or alarm bells. Extra simple, readable as tiny 12pt inline icon.

### list

Three short horizontal paper task strips stacked neatly, with one tiny square checkbox on the left of each. Slight offset makes the stack read as a collection/list layout. No binder loops, no circular arrows and no calendar grid.

## Delivery

`assets/header-icons/*.webp`: lossless WebP with transparency, 22px base, 44px (@2x), and 66px (@3x). `HeaderIcon` sets the visible point size for each toolbar position.
