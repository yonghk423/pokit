# 일러스트와 아이콘

갱신일: 2026-10-27

## 그림 장면

- 주인공의 일상을 보여주는 잉크 드로잉과 따뜻한 종이 배경을 유지합니다. 얼굴·동작·환경이 한 장면으로 읽혀야 합니다.
- 기존 장면 에셋을 손볼 때는 승인된 인물과 그림체를 참조합니다. 새 표정·자세·머리 모양은 장면의 행동과 맥락에 맞춥니다.
- 포인트 색을 제한적으로 사용하고 이미지 전체에 새 색 필터를 일괄 적용하지 않습니다.
- 기존 장면 생성 기록은 `assets/activity-illustrations/prompts.md`, 장면 목록은 `src/pages/day-plan/lib/heroSceneImages.ts`에서 확인합니다.

## 해상도와 렌더링

- 앱의 장면·카드·썸네일은 **960px 계열 소스**를 사용합니다. 480px 소스를 다시 섞지 않습니다.
- `src/pages/day-plan/lib/heroSceneThumbnails.ts`의 정적 등록과 `HeroSceneImage.tsx`의 공용 렌더링을 먼저 사용합니다.
- 960은 파일 규격을 가리킵니다. 세로 장면이 720×960인 것처럼 실제 가로·세로 비율은 파일마다 확인합니다.
- 작은 이미지의 디코딩 결과를 큰 상세 화면에 재사용해 흐려지지 않도록 합니다. 캐시·이미지 키 변경만으로 모든 네이티브 캐시 문제가 해결된다고 가정하지 않습니다.
- 여러 캐릭터가 있는 시트를 이동시켜 한 장처럼 보이게 하지 않습니다. 실제 화면에서는 캐릭터별 독립 이미지로 렌더링해 옆 캐릭터가 비치지 않게 합니다.
- 날씨 캐릭터는 상세 모달에서 현재 날씨와 계절에 맞는 항목을 선택합니다. 메인 화면에 새 큰 캐릭터를 임의로 추가하지 않습니다.

## 만년필 아이콘

- 단순한 조작 아이콘은 기존 코드 기반 아이콘과 `penContour`를 확장합니다. 크기가 바뀌어도 의미가 읽혀야 합니다.
- 일러스트형 에셋은 투명 배경을 보존합니다. 종이 배경이 필요한 장면과 투명 아이콘을 구분합니다.
- 필압의 변화, 약한 선 겹침, 열린 여백을 사용합니다. 진한 그림자·과한 해칭·큰 장식으로 작은 아이콘을 채우지 않습니다.
- 기능의 핵심 단서가 빠지면 안 됩니다. 예: 추가의 +, 새로고침의 화살촉, 닫기의 X.
- 인물 장면·작은 조작 아이콘·튜토리얼 안내 캐릭터는 용도에 따라 크기와 디테일을 다르게 조절합니다.

## 기존 에셋 등록

- 헤더 아이콘: `assets/header-icons`, `src/shared/ui/header-icon/index.tsx`, `sources.ts`의 실제 등록 경로를 확인합니다.
- 메이트 아이콘: `assets/routine-icons`, `src/shared/lib/routineIllustrationCatalog.ts`, `src/shared/ui/icon-symbol/routineIllustrationSources.ts`.
- `routine:` ID와 기존 저장된 시스템 심볼 ID는 데이터 호환성을 유지합니다. 표시 이름을 바꾸면서 저장 ID까지 바꾸지 않습니다.
- 작은 래스터 아이콘은 필요한 배율의 에셋을 함께 준비합니다. 등록되지 않은 파일명이나 존재하지 않는 원본 경로를 문서만 보고 추정하지 않습니다.
- 홈 화면 위젯이 시스템 심볼을 쓰는 경우 앱의 이미지 등록과 별도로 매핑을 확인합니다.

## 생성·검증 도구

- `scripts/generate-comic-thumbnails.py`: 외부 마스터로 960px 장면과 정적 등록을 생성합니다. 현재 번들 파일은 불필요하게 재압축하지 않습니다.
- `scripts/prepare-routine-illustration.py`: 메이트 아이콘의 배율별 WebP를 준비합니다.
- `scripts/verify-routine-illustrations.py`: 메이트 아이콘의 등록과 에셋을 검증합니다.
- 에셋 삭제·교체의 확인 범위는 [에셋 관리](../ops/assets.md)를 따릅니다.
