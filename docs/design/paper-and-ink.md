# 종이와 만년필 디자인

갱신일: 2026-10-27

## 목표

**그림 장면과 손글씨가 놓인 종이 다이어리**처럼 보이게 합니다. 화면의 장식보다 장면, 이름, 할 일, 기록을 먼저 읽을 수 있어야 합니다. 따뜻함은 종이와 선에서 표현하고, 조작 방식은 명확하게 유지합니다.

## 종이와 잉크

- 화면 바탕은 밝고 차분한 종이색과 은은한 질감을 사용합니다. 장면 일러스트의 따뜻한 종이색은 원본을 존중합니다.
- 본문과 조작부의 중심은 검정·차콜 계열 잉크입니다. 일반 버튼이나 선택 상태에 민트 면을 기본 적용하지 않습니다.
- 일반 버튼은 투명한 면이나 종이 면 위에 만년필 선을 사용합니다. 브라운 면을 기본 버튼 스타일로 새로 도입하지 않습니다.
- 삭제·오류 같은 의미가 필요한 색과 캐릭터·장면의 포인트 색은 역할에 맞게 사용합니다.
- 다크 모드에서는 글자·선·종이 면의 대비를 확인합니다. 라이트 모드 잉크색을 그대로 복사해 읽기 어렵게 만들지 않습니다.

`src/shared/config/retroFlat.ts`, `theme.ts`는 기존 화면이 함께 쓰는 구현 토큰입니다. 문서의 갱신만으로 모든 레거시 토큰이 새 스타일에 맞춰 변경되었다고 가정하지 않습니다.

## 만년필 선과 형태

- 필압에 따라 굵기가 조금 달라지는 선과 절제된 겹선을 사용합니다. 여러 번 두껍게 덧칠한 연필 테두리처럼 만들지 않습니다.
- 새 조작부는 `src/shared/ui/pen-frame.tsx`의 `PenFrame`, `penContour`와 기존 만년필 아이콘을 먼저 검토합니다.
- 전체 프레임과 선택 표시 모두 기능을 알아볼 수 있을 정도로만 흔들림을 줍니다.
- 이미지와 모달의 모서리는 부드럽게 처리합니다. 모든 화면을 직각으로 강제하거나 모든 버튼을 큰 알약 모양으로 통일하지 않습니다.
- 큰 모달·장면 카드의 둥근 모서리가 실제로 보이는지 확인합니다. 투명 자식·이미지의 클리핑도 함께 맞춥니다.
- 그림자는 종이가 겹치거나 카드가 움직이는 깊이를 전달할 때 은은하게 사용합니다.

## 글꼴과 문구

- `ThemedText`, `ThemedTextInput`, `src/shared/lib/ui-font`를 사용해 사용자가 선택한 글꼴과 크기를 존중합니다.
- 기본 글꼴은 `appFontIds.ts`의 현재 값으로 확인합니다. 특정 옛 영문 글꼴이나 모든 언어의 대문자 표기를 강제하지 않습니다.
- 긴 한국어·영어·일본어·번체 중국어 문구가 잘리지 않아야 합니다. 이름과 메모가 길어져도 주변 조작부가 밀려나지 않아야 합니다.
- 줄이 있는 입력칸은 초기 다섯 줄을 넘어가거나 스크롤해도 줄과 본문의 관계가 유지되어야 합니다.

## 장면과 주인공 선택

- 주인공 선택 카드는 화면 좌우 공간을 활용하고, 대표 이미지는 작고 간결하게 표시합니다.
- 대표 이미지 오른쪽에는 세로 썸네일 목록을 둡니다. 목록은 위아래로 넘길 수 있고 스크롤 막대는 숨깁니다.
- 썸네일을 누르면 대표 이미지가 바뀌고 해당 주인공을 선택합니다. 이름 입력과 튜토리얼 동작도 유지합니다.
- 불필요한 소개 문구를 반복해서 넣지 않습니다. 이름과 명확한 조작부를 우선합니다.
- 주인공 선택의 작은 미리보기와 일기를 펼쳐 보는 큰 장면 카드는 목적이 다릅니다. 둘의 크기를 하나의 전역 상수로 묶지 않습니다.
- 주인공·장면 원본의 비율을 찌그러뜨리지 않습니다. 의도한 크롭이 아니라면 인물의 얼굴·손·발을 임의로 자르지 않습니다.

## 작은 아이콘과 빈 상태

- 새 일기가 없는 보관함에는 **빈 노트와 + 표시**로 추가 행동을 안내합니다. 이 그림을 누르면 새 일기 만들기로 이어집니다.
- 검색 결과 없음과 기록 자체가 비어 있음은 구분합니다.
- 새로고침은 화살촉이 분명한 회전 화살표, 닫기는 알아보기 쉬운 X를 사용합니다.
- 보이는 아이콘이 작아도 누를 수 있는 영역은 충분히 확보합니다. 접근성 이름은 번역된 텍스트로 제공합니다.
- 의미를 전달하지 않는 장식과 긴 빈 상태 문구를 함께 쌓지 않습니다.

## 모션과 튜토리얼

- 카드를 눌렀을 때 회전하며 상세로 들어가는 모션을 유지합니다. 오류 수정이나 크기 조절을 이유로 없애지 않습니다.
- 장면 상세를 닫을 때 이동 전·후 이미지가 동시에 보이지 않아야 합니다.
- 튜토리얼은 현재 표시된 실제 버튼을 만년필 표시로 가리킵니다. 단순한 큰 원을 대충 씌우지 않습니다.
- 튜토리얼의 ‘나중에’와 사용자가 직접 누르는 버튼은 같은 다음 화면·상태로 이어집니다.
- 키보드, 모달, 날씨 조회 실패, 화면 복귀에도 표시 위치와 안내 대상이 일치해야 합니다.

## 반응형과 입력

- iPhone, iPad, 좁은 창의 사용 가능한 폭과 높이로 배치합니다. 태블릿의 메인 장면을 휴대폰 최대 폭으로 고정하지 않습니다.
- 바깥 여백을 늘리거나 화면 전체를 확대하는 방식으로 큰 기기에 대응하지 않습니다.
- 썸네일·추가 버튼·닫기 버튼은 큰 이미지에 가려지지 않아야 합니다.
- 스크롤 막대를 숨겨도 스크롤과 터치 탐색은 유지합니다.
- 키보드가 열린 상태의 이름·메모·할 일 입력과 저장·닫기 동작을 실제로 확인합니다.
